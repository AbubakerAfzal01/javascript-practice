# JavaScript Practical Course

> A hands-on, day-by-day JavaScript learning path, built through writing code myself, testing it in the browser, documenting it, and pushing with Git.

This repository contains my JavaScript practice (Stage 1 of my web development path). The focus is on understanding what I build, not copying working code.

The goal is simple:

**Learn -> Practice -> Build -> Document -> Commit -> Push**

> This course is actively in progress. Days and projects are added only after they are tested and pushed.

---

## Course Roadmap

| Phase | Days | Focus |
| :--- | :---: | :--- |
| 1. Foundations | 01-07 | Script tag, console, let/const, data types, operators, conditions, loops |
| 2. Functions and Data | 08-18 | Functions, arrays, objects, template literals, string/number/Math/Date methods |
| 3. The DOM | 19-33 | Selecting, events, forms, validation, event delegation, small projects |
| 4. Async and Browser APIs | 34-46 | Timers, promises, fetch, async/await, JSON, localStorage |
| 5. Core JavaScript | 47-54 | Destructuring, spread/rest, closures, this, modules, classes |
| 6. Debugging and Project | 55-60 | DevTools debugging, medium project, revision, assessment |

## Daily Learning Structure

```text
Review / Rewrite   -> yesterday's task from memory
Learn              -> one concept, with the reason why
Practice           -> I write the code myself
Test               -> run in browser, report real result
Challenge          -> small no-hint task
Document           -> notes.txt
Git Workflow       -> add, commit, push, verify
```

Every 7th day has no new topic: I build one small thing alone, using only MDN and my notes.

## Code Style

* const by default, let only when a value changes, never var
* === and !== only
* camelCase names that describe the value
* Semicolons, double quotes, 4-space indentation
* Short comments that explain why, not what
